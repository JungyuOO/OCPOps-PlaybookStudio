작업내용

구분 요약
추가신규 기능 파일 OpenShift Lightspeed 클라이언트, 외부 답변 아티팩트, viewer 연동, 테스트용 로컬 응답 서버, pgvector 기반 검색 보강, 신규 평가·테스트 파일이 추가되었습니다.
수정기존 기능 파일 채팅 응답 파이프라인, citation 매핑, viewer 라우트, 설정값, 배포 설정, 프론트엔드 Workspace 표시 영역, PostgreSQL 적재 흐름이 수정되었습니다.
삭제Qdrant 파일 Qdrant 기반 course/indexer/ingestion/store 파일과 OpenShift Qdrant seed job이 제거되었습니다.
이름변경테스트 파일 Qdrant payload 테스트가 검색 payload 테스트로 이름이 변경되었습니다.
변경의 중심은 두 가지입니다. 첫째, Qdrant 의존을 걷어내고 PostgreSQL/pgvector 기반으로 통합했습니다. 둘째, OpenShift Lightspeed 답변을 PBS 채팅 응답·참조문서·viewer 흐름에 연결했습니다.
