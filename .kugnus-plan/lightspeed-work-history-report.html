6. 감사 로그와 증명 방식

화면 배지는 단독 표시가 아니라 호출 결과와 같은 artifact를 기준으로 연결됩니다.

증명 값 의미
answer_source=lightspeed_with_pbs_rag 최종 답변 생성에 OpenShift Lightspeed 응답이 사용됨
status=used OpenShift Lightspeed API 호출 성공
badge_applied=true 화면에 Lightspeed 배지를 표시할 조건 충족
viewer_path=/external/lightspeed/{artifact_id} Lightspeed 응답 원문 artifact를 PBS Viewer에서 열 수 있음
conversation_id OpenShift Lightspeed 응답 식별값
referenced_documents OpenShift Lightspeed가 반환한 공식 문서 목록 수 
docker compose logs -f app | Select-String "openshift_lightspeed_call_audit"

8. 개선 항목

항목 현재 상태 개선 방향
긴 범위 질의 처리 모니터링 설치 조건처럼 공식 문서 탐색 범위가 넓은 질문은 Lightspeed 응답이 설정된 timeout을 초과할 수 있습니다. 현재는 답변 중단을 방지하기 위해 PBS 내부 근거로 fallback합니다. 질문 정규화와 비동기 보강을 통해 Lightspeed 응답 확보율을 높입니다.

9. 보고 문장

PBS는 OpenShift 운영 질문에 대해 OpenShift Lightspeed 공식 답변을 우선 호출하고, 그 결과를 citation [1]과 Viewer artifact로 고정한다. PBS 내부 Gold Playbook과 사용자 문서 근거는 [2] 이후 보조 근거로 함께 제공한다.

Lightspeed 배지는 단순 표시가 아니라 artifact_id, conversation_id, viewer_path, lightspeed_calls.jsonl 감사 로그로 검증 가능한 호출 결과를 의미한다.
